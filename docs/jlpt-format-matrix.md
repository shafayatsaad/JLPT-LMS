# JLPT format matrix

Checked against the official JLPT pages on 22 November 2026. Verify again before launch. The official JLPT notes that allotted times can change and listening times can vary slightly with the recording length.

## Timed test sections

| Level | Timed test section | Minutes | Score-report category mapping |
|---|---|---:|---|
| N1 | Language Knowledge (Vocabulary/Grammar) + Reading | 110 | Language Knowledge and Reading are reported separately |
| N1 | Listening | 55 | Listening |
| N2 | Language Knowledge (Vocabulary/Grammar) + Reading | 105 | Language Knowledge and Reading are reported separately |
| N2 | Listening | 50 | Listening |
| N3 | Language Knowledge (Vocabulary) | 30 | Language Knowledge (Vocabulary/Grammar) |
| N3 | Language Knowledge (Grammar) + Reading | 70 | Grammar maps to Language Knowledge; Reading maps to Reading |
| N3 | Listening | 40 | Listening |
| N4 | Language Knowledge (Vocabulary) | 25 | Language Knowledge (Vocabulary/Grammar) + Reading |
| N4 | Language Knowledge (Grammar) + Reading | 55 | Language Knowledge + Reading |
| N4 | Listening | 35 | Listening |
| N5 | Language Knowledge (Vocabulary) | 20 | Language Knowledge (Vocabulary/Grammar) + Reading |
| N5 | Language Knowledge (Grammar) + Reading | 40 | Language Knowledge + Reading |
| N5 | Listening | 30 | Listening |

Timed sections and score-report categories are separate fields in the data model. Never label raw practice performance as an official JLPT scaled score.
